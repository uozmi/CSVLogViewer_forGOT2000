# CSVLogViewer_forGOT2000
GT2000シリーズの運転ログCSVをwebUIで見れる
<img width="1919" height="917" alt="image" src="https://github.com/user-attachments/assets/28d45d7f-1ce9-43e7-b298-b62a25a8cd7a" />

# 背景
CSV形式のデータをExcelを使ってグラフ化するのは手間である。
また表示範囲の変更や拡大縮小、表示するデータの切り替えに手間がかかる

CSVデータの確認が必要となるトラブル発生時のシチュエーションに特化した、webUIアプリケーションを作成した
