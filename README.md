# CSVLogViewer_forGOT2000
PLC運転ログ（CSV）を、マウス操作だけで即時にグラフ化・比較できるビューワーです。

# 背景
従来はグラフ化に手間がかかるため誰もグラフを作らず、生データを目で追って「脳内デコード」していました。  
その結果、情報伝達がボトルネックになり、意思決定がなかなか進まない問題がありました。  
「グラフ化する」ではなく「グラフを業務の道具にする」をコンセプトに、  
トラブルの原因究明や、データ分析の議論の中心となるような、CSV形式になった運転データを動的に扱えるツールを作りました。
